# TaskBang AI — Project Context

## Platform Overview

TaskBang AI is a zero-budget MVP micro-task marketplace designed to connect Clients and Workers seamlessly.

## Core Flow

Client → TaskBang AI → Worker → Work Completion → Verification → Earnings → Withdrawal

## Business Rules

- Clients post tasks with specified budgets and requirements.
- Worker payout + TaskBang AI margin are governed via Admin-side logic.
- Prevent multi-account abuse per device.
- Standard roles: WORKER, CLIENT, ADMIN.
